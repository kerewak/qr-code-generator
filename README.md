# QR Kod Oluşturucu

Bu proje, girilen bir linki QR koda dönüştürüp PNG olarak kaydeden basit bir Java uygulamasıdır.

## Gereksinimler
- Java yüklü olmalıdır

## Kullanım
1. Projeyi indir
2. Terminalde proje klasörüne git
3. Programı çalıştır
4. İstenen linki gir
5. Proje klasöründe QR kod PNG olarak oluşturulur

## Notlar
- ZXing kütüphanesi `lib` klasöründe zaten mevcut, ayrıca indirmen gerekmez.
